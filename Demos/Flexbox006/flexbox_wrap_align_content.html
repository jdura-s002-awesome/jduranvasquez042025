FlexboxWAC - Flex-Wrap Align-Content Manuel Chagoyan • Yesterday (Edited 10:07 AM) 30 points Due Feb 27 FlexboxWAC Flexbox is a layout model for arranging html elements (horizontally or vertically) within a container (box), in a flexible and responsive way. Technique when placing elements next to one another Put elements in a box (div) Set the box to display flex Once elements are placed in a box you can control their horizontal and vertical placement. In this demo/assignment we learn we can wrap overflowing flexbox children with the flex-wrap and align-content properties. Once a container is set to display flex, the children elements can be wrapped as needed. Align-content allows you to align the wrapped elements as a group.
